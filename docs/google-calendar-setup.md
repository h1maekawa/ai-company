# Googleカレンダー連携の設定

朝会（`/planning`）で作ったタイムブロッキングを、Googleカレンダーへ自動同期するための一度きりの設定です。
**設定しなくても「ICSファイルでダウンロード」は今すぐ使えます**（ダウンロードしたファイルを開けばカレンダーに取り込まれます）。自動同期が要るときだけ以下を行ってください。

所要時間：10分程度。すべてご自身のGoogleアカウントでの操作になります。

---

## 1. Google Cloudでプロジェクトとカレンダー APIを用意する

1. https://console.cloud.google.com/ を開く
2. 上部のプロジェクト選択 → 「新しいプロジェクト」→ 名前は `ai-company` などで作成
3. 検索窓で「Google Calendar API」→ **有効にする**

## 2. OAuth同意画面

1. 左メニュー「APIとサービス」→「OAuth同意画面」
2. User Type は **外部** を選択して作成
3. アプリ名（例：`AI Company`）とご自身のメールアドレスを入力して保存
4. 「対象」（Audience）で **テストユーザー** にご自身のGoogleアカウントを追加
   - 公開申請は不要です。テストユーザーのままで動きます

## 3. OAuthクライアントIDを作る

1. 「APIとサービス」→「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**
2. アプリケーションの種類：**デスクトップアプリ**
3. 作成後に表示される **クライアントID** と **クライアントシークレット** を控える

> デスクトップアプリ種別にしておくと、次のリフレッシュトークン取得が一番簡単です。

## 4. リフレッシュトークンを取得する

1. https://developers.google.com/oauthplayground/ を開く
2. 右上の⚙️（設定）→ **Use your own OAuth credentials** にチェック
   → 手順3のクライアントID・シークレットを入力
3. 左のリストから **Calendar API v3** → `https://www.googleapis.com/auth/calendar` を選択
4. **Authorize APIs** → ご自身のGoogleアカウントで許可
   （「このアプリは確認されていません」と出たら「詳細」→「（アプリ名）に移動」で進めます）
5. **Exchange authorization code for tokens** を押す
6. 表示された **Refresh token** を控える

## 5. 環境変数を設定する

Vercel（本番）と `ai-secretary/.env.local`（ローカル）の両方に設定します。

```
GOOGLE_CLIENT_ID=<手順3のクライアントID>
GOOGLE_CLIENT_SECRET=<手順3のクライアントシークレット>
GOOGLE_REFRESH_TOKEN=<手順4のリフレッシュトークン>
GOOGLE_CALENDAR_ID=primary
```

- `GOOGLE_CALENDAR_ID` は省略可（既定は `primary` ＝メインのカレンダー）
- 専用カレンダーへ入れたい場合は、Googleカレンダーの「設定」→ 対象カレンダー →「カレンダーの統合」にあるカレンダーIDを設定してください
- Vercelは環境変数の追加後に **再デプロイ** が必要です

## 6. 動作確認

`/planning` で時間割を生成し、**📅 Googleカレンダーへ同期** を押します。
「Googleカレンダーへ◯件同期しました」と出れば完了です。

---

## 挙動のメモ

- 同期は**その日の分を作り直す**方式です。アプリが作ったイベントだけを消してから入れ直すので、時間割を作り直しても古いブロックが残りません
- 手動で入れた予定や他アプリの予定は消しません（このアプリが作った印のあるイベントだけを対象にします）
- タイムゾーンは Asia/Tokyo 固定です

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「Googleの認証に失敗しました（400）」 | リフレッシュトークンが失効。手順4をやり直す |
| 「Googleカレンダー連携が未設定です」 | 環境変数が読めていない。Vercelなら再デプロイが必要 |
| 同期は成功するが予定が見えない | `GOOGLE_CALENDAR_ID` が別カレンダーを指していないか確認 |
